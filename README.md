# 日本地名なぞなぞクイズ

## アプリ概要
HTML / CSS / JavaScript だけで動作する完全静的なクイズサイトです。50問の地名なぞなぞから毎回ランダムで10問を出題し、入力ゆれや軽微なタイプミスを吸収しながら判定します。10問終了後に、正解数・正答率・振り返り一覧・SNSシェア（X / LINE / Facebook / コピー / ネイティブ共有）を表示します。

## ファイル構成
- `index.html` : 画面テンプレートと基本構造
- `style.css` : パステル調のカードUI、レスポンシブ、トーストなどのスタイル
- `script.js` : 問題データ、状態管理、判定ロジック、画面描画、シェア機能
- `README.md` : この説明

## ローカルでの確認方法
### 1) 直接開く
`index.html` をブラウザで開くだけで動きます。

### 2) 簡易HTTPサーバーを使う
```bash
python3 -m http.server 8000
```
その後、`http://localhost:8000` にアクセスしてください。

## カスタマイズ方法
### 問題を追加する
`script.js` 内の `quizData` に以下形式で要素を追加します。

```js
{ question: "問題文", answer: "正式回答", yomi: "よみ", aliases: ["別表記1", "別表記2"] }
```

### aliases を増やす
同じ地名でも表記違い（漢字・かな・カナ・省略）を `aliases` に追加すると、正解扱いの範囲を広げられます。

## 判定ロジック概要
1. **正規化**
   - 前後空白除去
   - 全角半角の吸収（`NFKC`）
   - 大文字小文字吸収
   - ひらがな / カタカナ吸収
   - 空白・一部記号の除去
2. **別名判定**
   - `answer` / `yomi` / `aliases` のいずれかと一致で正解
3. **軽微 typo 許容**
   - レーベンシュタイン距離を使用
   - 語の長さに応じて距離1〜2まで許容
   - 長さ差が大きい入力は不正解にして誤判定を抑制
